# Exports

Generated by `tools/build_exports.py` from the repository data. Do not edit by hand: CI fails if these files differ from a fresh build.

| Path | What |
|------|------|
| `blocklists/asn-block.txt` | ASNs recommended `block` |
| `blocklists/cidr-block.txt` | Curated prefixes recommended for blocking |
| `blocklists/blocklist.csv` | Both, with entity, tier, basis and validity window |
| `stix/bph-bundle.json` | STIX 2.1 bundle |
| `misp/` | MISP feed (manifest.json, hashes.csv, one event per entity) |

Indicators expire 30 days after the data was last checked. Inclusion rules, formats and caveats are in [`docs/EXPORTS.md`](../docs/EXPORTS.md).
